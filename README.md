 Sobre o projeto:

Site de uma empresa de serviços contábeis,
reconstruído a partir do conteúdo da avaliação A1.1.

 Funcionalidades:

- Cadastro de solicitações de orçamento.
- Cadastro de mensagens de contato.
- Listagem dos serviços cadastrados no banco de dados.

Tecnologias utilizadas:

- HTML
- CSS
- JavaScript
- PHP
- MySQL

Como executar:

1. Instalar o XAMPP.
2. Colocar os arquivos na pasta htdocs/senca-contabil.
3. Iniciar o Apache e o MySQL.
4. Acessar localhost/phpmyadmin.
5. Importar o arquivo banco.sql.
6. Acessar localhost/senca-contabil.

O banco possui três tabelas:

- servicos
- contatos
- orcamentos

O PHP realiza as operações de INSERT e SELECT,
e o JavaScript faz a comunicação com o back-end.

A sintaxe dos códigos foi verificada.
A integração com o MySQL precisa ser testada no XAMPP.
